# AfriTalent Generated Website Assets

These images were generated for the AfriTalent public website using a photorealistic editorial direction:

- `afritalent-hero-global-talent.png` - homepage hero atmosphere and brand texture.
- `afritalent-smart-search-workspace.png` - smart aggregation/search feature image.
- `afritalent-collaboration-hiring.png` - CTA collaboration background.

Visual direction:

- Premium Africa-to-global hiring platform, not generic job-board stock imagery.
- Emerald/teal, amber, and zinc-neutral palette to match existing UI tokens.
- No readable in-image text, logos, flags, or fake brand names.
- Wide 16:9 crops suitable for responsive homepage sections and Canva campaign reuse.

Figma/Canva handoff:

- Use these assets as image fills in Figma frames with the same 16:9 crop.
- For Canva banners, keep text outside the raster image and use dark emerald overlays for legibility.
- Keep the originals in this folder and create resized/exported variants separately.
