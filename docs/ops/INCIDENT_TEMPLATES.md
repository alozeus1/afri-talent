
## External Status Page Template

```text
We are investigating an issue affecting [service or workflow]. Users may experience [impact].
Our team is actively working on mitigation. Next update in [15/30] minutes.
```

## External Recovery Update Template

```text
We identified the issue affecting [service or workflow] and have applied mitigation.
We are monitoring recovery and validating that [key user flow] is working normally again.
Next update in [15/30] minutes unless resolved sooner.
```

## External Resolution Template

```text
The issue affecting [service or workflow] has been resolved.
We have validated recovery for [key user flow] and are continuing to monitor.
If you still experience problems, contact support with timestamps and the affected workflow.
```
