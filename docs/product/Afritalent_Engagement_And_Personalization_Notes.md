# AfriTalent Engagement And Personalization Notes

Date: 2026-04-28

## Implemented Or Strengthened

- Candidate dashboard already includes rule-based next-best-action guidance.
- Job cards now provide clearer trust/action feedback instead of fake engagement counts.
- Interview cards support one helpful vote per local session and clearer sample-scenario labeling.
- Salary guidance links high-opportunity roles to search and learning actions.
- Early-access feedback capture exists for key workflows and stores local feedback safely where backend storage is not yet wired.

## Recommended Rule-Based Signals

- Profile completeness.
- Resume uploaded or builder progress.
- Saved jobs count.
- Application tracker status.
- Preferred role and top skills.
- Learning completion state.
- Interview practice progress.
- Trust/scam warnings viewed.

## Future Enhancements

- Persist recently viewed jobs per account.
- Add “continue learning” and “continue interview practice” panels backed by user progress.
- Add in-app reminders for follow-up-needed applications.
- Add admin review for early tester feedback once backend feedback storage is finalized.
- Add analytics events for next-best-action clicks and completed recommendations.
